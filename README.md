# Additional Arrows

This mod adds new custom arrows to Minecraft.

## Features

This mod is currently focused on **arrows**. Custom bows and other related items may be added in the future, but they are **not part of the current scope**.

### Current Features

*   Custom textures for each additional arrow
*   Explosive arrow that blows up on impact
*   Lightning arrow that strikes the target with lightning

### Planned Features

*   Lava arrow which adds lava to the target blocks

## Crafting

Craft receipe of `blow up arrow`:

2B: TNT

3B: Arrow

Craft receipe of `electric arrow`:

2B: Lighting Rod

3B: Arrow

## Servers

This mod is **not server-side**. This means that if you want to use it on a server, **every player must install the mod on their client**.

**Server-side compatibility has not been tested yet.**
